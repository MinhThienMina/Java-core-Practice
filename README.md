## Yêu cầu môi trường

- JDK 17 hoặc 21 (dùng cú pháp Java hiện đại: pattern matching `instanceof`, switch expression, `var`...)
- Kiểm tra phiên bản:
  ```bash
  java -version
  javac -version
  ```

## Practice 1 — Shape / Rectangle / Circle


**Chạy:**

```bash
cd Practice1

java Practice1
```

## Practice 2 — Quản lý kho hàng siêu thị

**Chạy:**
```bash
cd Practice2
javac Practice2.java
java Practice2
```
Chương trình có menu tương tác — nhập số (0-5) rồi Enter để chọn chức năng, `0` để thoát.

## Practice 3 — Quản lý phương tiện (công an giao thông)

Quản lý 3 loại phương tiện: `Car` (ô tô), `Motorbike` (xe máy), `Truck` (xe tải), kế thừa từ lớp trừu tượng `Vehicle`. Mỗi phương tiện có một chủ sở hữu (`Owner`).

**Chạy:**
```bash
cd Practice3
javac Practice3.java
java Practice3
```
